角色與妖怪影象署名 / Art credits
=================================

本遊戲的主角與妖怪影象使用 Liberated Pixel Cup (LPC) 素材，
由 Universal LPC Spritesheet Character Generator 的圖層合成，並對部分圖層重新著色（顏色已修改）。
Generator: https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator

合成後的精靈圖以相同授權條款（CC-BY-SA 3.0 / GPL 3.0）分享。
